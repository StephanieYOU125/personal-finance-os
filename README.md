# Personal Finance OS

A personal finance system for reviewing spending patterns, major purchases, travel costs, subscriptions, and self-investment decisions.

## 核心目的

這不是單純的記帳工具，而是一份「財務使用說明書」。

重點不是只問：

> 我花了多少？

而是問：

> 這筆錢是否符合我現在的人生主線？

## 目前功能

- 財務狀況與問題摘要
- 大額支出分級規則
- PART 決策框架：Purpose / Alternative / Return / Timing
- Survival / Growth / Exploration / Relationship / Risk / Future 資源配置
- 訂閱與旅行投資回顧
- 年度探索預算與儲蓄比例設定
- 大額支出三個月後檢討
- 手機版響應式介面
- 使用 localStorage 儲存個人設定

## 隱私

網站程式碼可放在 GitHub，但不要把完整信用卡號、帳戶資料或其他敏感財務資訊寫進 repository。

使用者在頁面中填寫的設定預設只保存在目前瀏覽器的 localStorage。

## GitHub Pages

此專案的首頁為 `index.html`，因此啟用 GitHub Pages 後，可以直接作為網站入口。
