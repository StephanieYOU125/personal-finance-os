我真正要解決的三個問題

01

有意義 ≠ 高報酬

旅行、展覽、課程、書籍和工具都可能有意義，但有意義不能證明它現在值得花這筆錢。

02

探索容易沒有天花板

「難得一次」「可以學到東西」「未來可能有用」都能合理化支出，所以探索一定要有年度額度。

03

投入有記錄，產出沒追蹤

英文課、科技展、旅行、AI工具都要追蹤最後產生的能力、作品、研究想法或決策。

典型風險：小錢不太在意，大錢又容易用「這是投資自己」合理化。真正需要控制的，不是一杯65元飲料，而是一年裡反覆出現的3,000、10,000、20,000元目的型支出。

未來支出規則

< NT$500
不必過度糾結，只檢查是否明顯重複或浪費。
NT$500–3,000
檢查是否已有同類訂閱、設備、課程或替代方案。
NT$3,000–10,000
一定做 PART：Purpose → Alternative → Return → Timing。
> NT$10,000
至少隔24小時再決定，不在旅途中、活動現場或興奮狀態立即購買。
> NT$30,000
做完整機會成本比較：如果不花這筆錢，可以換成什麼更重要的選項？

PART｜買之前問四題

P — Purpose

我要解決什麼問題？如果說不出具體問題，先不買。

A — Alternative

有沒有更便宜、免費、延後、借用或先試用的方法？

R — Return

會增加能力、健康、關係、作品、收入或未來選擇權嗎？

T — Timing

現在一定要做嗎？三個月後做，價值會明顯下降嗎？
